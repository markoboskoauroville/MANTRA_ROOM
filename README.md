# Chakra and Elements Toning (Mantra)

A meditation app for Android built on DJ Mantra's chakra toning: a guided toning with MilkDrop visuals, five element
stripes to sing along (A, U, I, O, A-U-I-O), a breath circle, a session timer with a soft bell, background play and a
gentle practice log. Offline, no account, no internet permission.

Download the latest version: https://github.com/markoboskoauroville/MANTRA_ROOM/releases/latest

## On the Mac: Meditation Room (Mantra)

The same room in a Swift window (folder `mac/`, since 15.11.2026): the MilkDrop visuals, all thirteen tracks in a loop
into any output (without changing the Mac's default), and the picture on a Logitech G815 keyboard as a small display.
Releases are tagged `mac-vN` (https://github.com/markoboskoauroville/MANTRA_ROOM/releases/tag/mac-v1); the app asks to
update at start.
